# Cocos 开发与验证的执行约束

授权：用户于2026-10-06明确要求后续Cocos项目开发、验证尽量使用CLI，运行检查通过Codex内置浏览器完成；可行后直接成为组织约束。共享方法为 `agents/shared/skills/cocos-cli-browser/SKILL.md`。

## 优先路线

所有角色在执行Cocos工程操作时，优先使用版本相容的脚本、引擎API和Creator CLI完成源码维护、资源处理、导入/构建与静态核验；优先用本地HTTP服务提供实际Web构建，再通过Codex内置浏览器检查画面、Canvas交互和可用的控制台/加载错误证据。Creator预览可用于开发探测，须注明其与正式构建的区别。

“优先”是默认执行选择，不是所有Cocos任务必须完全脱离编辑器。原生CLI通常提供构建能力，不等于具备任意场景编辑命令。Editor扩展API仍依赖Editor进程；独立cocos-cli须先核版本、序列化与资源兼容，不能默认安装或替换已锁定引擎。

只有操作本身需要编辑器、CLI缺少必要能力或实际执行存在明确阻塞时才使用Editor交互，并记录理由。内置浏览器不可用或缺少所需交互能力时，记录缺口并使用已授权的替代验证；不把普通外部浏览器、截图或Mock静默标为内置浏览器已验。已批准的设备、小游戏SDK、原生、性能或发布专项仍须在相应环境验证，Web结果不替代这些结果。

## Scene、Prefab和资源

在明确的Task范围与上游审批满足后，允许可审查、可重复的脚本转换Scene/Prefab文件，不再普遍要求先通过Inspector清空引用并由Editor保存。转换前记录工作区差异、原文件哈希和可恢复副本；转换只处理确定的对象/字段。删除序列化数组对象时必须完整更新嵌套 `__id__`、父子/组件/Prefab实例与覆盖关系，保留仍需的UUID、脚本身份、资源`.meta`与图像字节。禁止用猜测索引、广泛替换、重建UUID或删除元数据掩盖断链。

受影响工程必须经过对象图/活动资产引用核验、版本相容的Creator导入与构建、实际运行验证；检查覆盖Task涉及的场景/Prefab/脚本/构建入口，不能通过缩小构建范围掩盖应验证的引用。静态检查、导入、构建和运行分别给结果；缺失必需环节保持NOT_TESTED/BLOCKED。脚本检查只覆盖其声明的字段，不能冒充引擎反序列化或missing资源完整校验。

旧资源仅在归属明确、活动引用已解除且相关导入/构建/运行确认后正式清理；已在工作树删除的文件先核账，不能称为本轮新增产出。已批准母版、历史交付、Review与审批链保持可追溯。

## 构建与运行证据

使用当前项目锁定Creator版本。构建成功须同时有该版本的结束/成功日志、合理退出码、当前实际输出及基本加载验证；不能仅凭启动器或父进程返回判成功。Creator 3.8官方CLI的成功退出码可能是36，不能把所有非零统一判失败。固定构建目标、任务配置与来源版本/hash，排除旧输出冒充新构建。

后台本地服务默认只绑定loopback。核服务指向实际产物目录，记录进程、端口、URL、构建身份和验证时间；运行验证使用HTTP，不用file://。内置浏览器依据当前返回的工具文档与截图/DOM操作，Canvas没有语义定位时按最新截图坐标操作并复核；只读evaluate不用于注入状态或绕过真实输入。权限拒绝走正规授权处理，不通过改地址、外部浏览器、CDP或系统安全配置绕过。失败最多完成一次有证据的恢复；重复失败后改诊断方法或记真实BLOCKED，不无限重试同一请求。

## 角色责任与迁移

- Master：在Task中声明路线、涉及文件和验证证据；组织例外、跨角色Review与最终汇报。
- Producer：核对实际开始、构建/浏览器证据、阻塞、版本和审批，不把方法安装/规则生效等同功能或QA完成。
- Tech Lead：审查序列化、引用/UUID、工具兼容、构建与例外技术证据。
- Client：负责受控变更、CLI构建和实现级冒烟。
- QA：按已批计划执行内置浏览器功能/视觉检查；设备/平台/性能证据按现有QA规范保留。
- Art/UI/VFX：通过同版本运行画面评审接入效果；保留现有视觉审批和专业判断。
- Product/Server：需要操作Cocos时使用同一共享入口；各自范围、契约与职责不因此扩大。

本规则不新增普遍的用户审批步骤，也不减少原有Artifact、视觉和QA门禁。已批准任务在安全交接点引用新的补充执行约束，旧批准文档不覆盖；保留产品语义、质量标准和资源范围。此组织变更同步当前游戏、Studio主仓库及标准模板；未参与的既有游戏仍保持pinned。
