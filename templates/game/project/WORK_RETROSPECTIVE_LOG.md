# 工作流程复盘记录

Producer 按 `rules/work_retrospective.md` 在每个有明确结果的执行周期后追加简短记录。本文件记录流程观察，不代表 Artifact 用户批准或 QA 通过；重大或重复问题另见 `project/improvements/`。

## 记录模板

### <执行周期 ID>｜<关联 Task / Artifact 版本>

- Owner / 结果 / 证据路径 / 当前门禁：
- 起止时间、时区、总耗时与已知分段：
- 慢的判断依据：
- 主要原因（观察与推断分开）：
- 建议（最多三条；责任角色、预期作用、代价/风险、复核节点）：
- 后续复核：待复核 / 有效 / 无效 / 证据不足。
