# 日常 Git 提交与推送持续授权

- 日期：2026-09-29
- 授权：用户明确赋予 Agent 日常 Git 提交和推送能力，希望每次修改落地后直接推送。
- 范围：Studio Repository，以及当前或未来由本组织实际处理的 Game Repository；不主动改写其他未参与项目。
- 变更：获授权的文件修改完成并验证后，可直接按任务范围执行 `git add`、`git commit`、`git push`，无需逐次请示。提交和推送不代表 Artifact 获得用户审批。
- 边界：提交前核对仓库、文件、版本和敏感内容；父模板禁止混入游戏 Project Layer。远端冲突、保护分支或权限拒绝时停止并报告；不自动 merge、rebase、force-push 或历史改写。创建/切换分支、改 remote 等其他 Git 动作仍需单次授权。
- 评审：Producer 确认审批门禁、仓库分层与状态追踪；Tech Lead 确认嵌套仓库、锁文件真实 commit、远端分歧和危险操作边界。
- 验证：当前项目与主模板规则文件同步后核对一致；实际 Git 提交和推送结果按仓库分别记录。
- 回退：用户可随时撤销持续授权；撤销后恢复逐次请求，不回滚已完成的正常提交。
