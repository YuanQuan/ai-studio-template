# 视觉设计到正式资源的跨角色交接规范

- 类型：`CROSS_AGENT_CONTRACT`
- 用户授权：2026-10-03，用户明确要求先规范各部门角色标准，再继续项目工作。
- 范围：当前游戏 Studio Layer、主 Studio Layer 及标准小游戏模板默认项；其他已存在游戏保持 pinned。
- 参与评审：Art 提出视觉锚点、原创重绘与同尺度审稿规则；Tech Lead 补足首图前预签、视觉/技术双结论和 QA 阶段边界；Master 汇总并应用到全部角色。

## 决定

以 `rules/visual_production_contract.md` 为通用交接规则。已确认视觉先固化为可核对的锚点，生产美术在版权许可和可编辑母版约束下原创重绘，不得自行改变已批准设计。首张样张前 Art/Tech 对制作预案签认，样张和成品分别有 Art 视觉结论及 Tech 资源生产结论；Client 接入批准版本并提供运行画面，QA 分列功能、视觉和性能。缺少实图、运行或设备证据时写 `NOT_TESTED`。预算与视觉冲突由 Master 组织受影响角色和用户取舍。

## 验证与迁移

核对每个角色 `ROLE.md` / `CONSTRAINTS.md`、Artifact/Workflow/Approval 规则、主模板的空白 Art/Asset/UI/Test 默认项和两仓库文件一致性。已有运行中的任务在下一安全交接点应用新版本；历史失败样张与审批不被改写，也不追溯补造 `PASS`。

本文件只记录通用组织规则，不包含任何具体游戏的画风、角色、数值、目标机或资源文件。
