# Art 图片转 PSD 兜底方法

- 日期：2026-10-05
- 状态：APPLIED_CURRENT_GAME_AND_TEMPLATE；提交与推送状态以实际 Git 结果为准。
- 授权：用户明确指定 Art 无法直接生成 PSD 时使用 `bggg-creator-image2psd` skill 将当前图转换为 PSD。
- 范围：Art 角色能力与约束、视觉资源交接契约、转换证据要求及标准小游戏模板默认说明。属于组织级 Art 职责和交付方法变更，当前游戏与主 Studio 模板双同步；其他已有游戏保持 pinned。
- 边界：转换沿用当前图，保留源图、预览和图层来源；单图拆层须说明可编辑范围及补洞/重建内容。转换不能静默重画或改变已批准效果，也不跳过现有两次用户审批门禁。
- 验证：核对两仓 Studio Layer 一致、模板默认项同步、`git diff --check` 通过；不把具体游戏图片或任务记录带入模板。
