# 新项目初期的脑图头脑风暴方法

- 日期：2026-09-29
- 授权：用户明确建议未来所有项目初期先从头脑风暴开始，以简单表达抓住重点；Master 评估脑图可作为主要阅读入口。
- 范围：Studio 通用产品起步方法与标准小游戏模板；不包含任何具体游戏需求。
- 变更：新游戏和大型版本先产出简洁脑图及短说明，记录核心循环、模块编号与边界、确认方向、假设、待决问题和来源。方向收敛后再逐层细化产品总纲与功能 PRD。
- 评审：Product 确认脑图可减少初期叙述和修订成本，但短说明仍须保留语义与来源；Producer 确认同版本 Artifact、专业评审、用户审批、历史版本和 Dashboard 追踪不能省略。
- 验证：当前项目已制作脑图样例；主模板同步后核对规则与产品模板内容一致。此方法只改变初期表达顺序，不改变既有审批或正式开发输入门禁。
- 回退：撤销本次规则与模板增补，恢复原产品总纲模板文字；已存在的项目 Artifact 不自动删除或改写。
