# 自行切图直接交用户审核

- 日期：2026-10-05。
- 授权：用户明确要求“去掉切图效果复审环境环节，如果是你自己切的图，只要把结果告诉我，我来审核就行”。
- 类型：组织级 Workflow／Artifact Gate 变更；用户未限定仅当前项目，按仓库同步政策同步当前游戏 Studio 快照与主模板。
- 适用：本组织 Agent 自行从已批准 PSD 切图，或直接采用用户提供的 PSD 与其导出 PNG；当前单元示例1适用后一情形。
- 新流程：保留制作前方案审批、必要首图前预签、来源与版本记录；切片完成后由执行 Agent 核对源、图层映射、尺寸、文件和同尺度重组，直接向用户展示实际切片、重组图及已知限制。切图效果不再设置 Art／Tech／Master 专业复审或额外浏览器、Creator 预览环境作为用户审核前置门禁。用户对具体版本明确批准后，Client 才正式接入，技术、视觉运行及 QA 验证仍在接入阶段进行。
- 边界：用户这句话是对流程的批准，不是对任何具体切图版本的 Gate2 批准；历史 Review 保留，不追改结论。若用户退回，提交新版本。若发现确需改美术像素，先向用户说明范围及效果。
- 受影响角色：Art、Tech Lead、Client、Producer、Master、QA；由用户亲自承担切图效果审核，专业角色仍负责各自后续工程与运行质量。
- 验证：检查当前与模板的 `AGENTS.md`、`rules/visual_production_contract.md`、`rules/approval_protocol.md`、`rules/workflow.md`、`rules/artifact_contract.md` 口径一致；当前单元示例1按新门禁迁移，既有切片与重组证据不重做。
