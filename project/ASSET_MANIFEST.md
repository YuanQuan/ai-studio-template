## Asset Entry Template

每项资产建议记录：
- Asset ID。
- Type：character / environment / icon / ui / vfx / animation / audio / other。
- Owner。
- Purpose。
- Path。
- Size / Resolution。
- States / Variants。
- Source / Generation method。
- Integration status。
- Related Task ID。
