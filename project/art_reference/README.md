# Art Reference Repository

用于 Art Agent 收集和整理视觉参考、素材研究、风格样本和版权/来源信息。这里是“参考与研究库”，不是最终生产资产目录。

## Categories
- `characters/`：人物比例、服装、剪影、材质、动作参考。
- `scenes/`：场景、建筑、地貌、光照、氛围参考。
- `props/`：道具、装备、器物参考。
- `ui/`：UI 视觉语言、装饰、纹理、构图参考。
- `vfx/`：VFX 色彩、形态、节奏、材质参考。
- `misc/`：其他视觉研究。

## Reference Record
每个正式参考集合至少记录：
- 来源名称/链接或出处。
- 收集日期。
- 来源类型：原创/公开网页/素材库/生成式参考/其他。
- 已知授权或版权状态；未知时明确标记 `UNKNOWN`。
- 具体借鉴点：色彩、比例、材质、构图、文化元素、功能表现等。
- 禁止直接复制的保护性表达。
- 最终设计如何经过重组、抽象、多来源融合或重新创作形成自己的视觉语言。

## Copyright / Appearance Rules
- 参考可以用于研究与灵感，不等同于获得复制权。
- 不以单一受保护作品做一比一临摹、换色、微调或可识别的近似复制。
- 多素材融合也不能机械拼接受保护表达；目标是抽取通用设计语言后重新构成原创方案。
- 对知名角色、品牌标识、独特服装/道具造型、特定 UI trade dress、受保护角色外观等高风险参考，必须在 Art Brief / Review 中标记风险。
- 来源或授权不清时不得把参考素材直接当最终生产资产。
- 高版权/IP风险事项需进入 `project/research/ip_copyright/` 做进一步风险评估，必要时建议专业法律/授权确认。

## Relationship to Production
- `project/art_reference/`：参考、研究、来源记录。
- `deliverables/art/`：Art Agent 正式设计稿、原画、风格产物。
- `project/ART_GUIDE.md`：用户批准后长期有效的视觉基线。

只有用户批准的最终视觉版本才能成为 UI/VFX/Client 的正式下游输入。
