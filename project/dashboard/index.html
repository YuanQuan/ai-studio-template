Producer 页面维护规则

第一版采用静态 HTML；未来可在每次状态变化后由 Producer 同步刷新。

1. 任何角色一旦进入 IN_PROGRESS，立即登记 TASK_STARTED，并显示当前 Owner、关键节点和预期 Artifact 路径。
2. 每次 Artifact Draft、专业 Review、用户审批、Handoff、Blocked/Unblocked、实现完成、QA、DONE 等关键节点发生后同步更新页面。
3. 页面中的 Artifact 必须显示可追溯的真实仓库路径和版本；不得只写“PRD 已完成”“原画已完成”之类无法定位的描述。
4. 页面只展示正式事实，不推断用户审批；Draft / Revision / USER_REVIEW 版本不得显示为“已交付下游”。
5. 当前状态追溯到 WORKFLOW_STATUS，历史节点追溯到 MILESTONE_LOG，审批追溯到 APPROVAL_LOG，具体内容追溯到 Task / Artifact / Review 文件。
6. 后续如任务数量增多，可增加任务过滤、模块筛选、甘特视图或从结构化 JSON 自动生成页面。
