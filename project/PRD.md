# Product Requirements Document

## Status

当前没有已锁定的正式功能需求。

## Active Features

## Requirement Template

每个正式 Feature 至少记录：
- Feature ID / Name。
- Goal / User Value。
- In Scope / Out of Scope。
- Rules。
- User Flow。
- States / Edge Cases。
- Error Handling。
- Acceptance Criteria。
- Client / Server / UI / Art / QA Impact。

## Locking Rule

当 Master Agent 将某一规格宣布为 Locked 后，专业 Agent 不得为了实现方便静默改变其语义。需要变化时必须走 Change Request。
