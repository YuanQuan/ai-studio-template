# Art Guide

## Status

当前未确定正式美术风格。

## To Define

- 世界观与视觉关键词。
- 角色比例与造型语言。
- 场景风格。
- 色彩与材质。
- 图标 / 道具 / UI 插图规范。
- 动画与 VFX 风格关系。
- 目标分辨率、纹理和性能预算。

## Governance Rule

- Art Agent 是项目 Art Director / 视觉总监，负责长期维护主体美术方向和视觉一致性，防止角色、场景、道具、UI 视觉和 VFX 视觉在迭代中逐步偏离。
- Art 可以与用户进行多轮 Draft/Revision；影响整个项目的主体风格、角色视觉体系、UI 视觉语言或 VFX 主体视觉语言的版本，必须经过用户明确批准后才能写入本文件成为正式基线。
- UI Agent 负责布局、信息层级、交互和组件状态，但视觉风格/配色/装饰语言必须遵守本 Art Guide，并默认先经过 Art Review。
- VFX Agent 负责触发、时序、性能和实现规格，但色彩、材质、形态和世界观视觉语言必须遵守本 Art Guide，并默认先经过 Art Review。
- Art 的重大视觉产物必须明确设计思路/理由，说明为什么这样设计以及如何服务世界观、产品体验和长期一致性。
- 视觉参考与来源记录维护在 `project/art_reference/`；参考可用于研究和灵感，但不自动获得复制权，不得把受保护作品的可识别表达通过临摹、换色、微调或机械拼接当作原创。
- 高版权/IP/品牌/trade dress/独特外观风险进入 `project/research/ip_copyright/` 做进一步评估。
