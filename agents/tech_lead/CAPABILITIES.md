# Tech Lead Agent — Capabilities

第一轮能力校准已完成。

## 已确认能力范围
- 客户端/服务端架构拆分与模块边界设计。
- Cocos Creator + TypeScript 客户端架构治理。
- Node.js + NestJS + TypeScript 服务端架构治理，当前采用模块化单体，不采用微服务作为默认方案。
- Monorepo 工程结构设计与共享 package 边界设计。
- 标准 WebSocket（服务端 `ws`）网络层、连接管理、请求/响应、服务端推送与实时消息模型设计。
- Protobuf 协议设计、字段兼容演进、前后端生成代码与共享 Contract 治理。
- MySQL 持久化边界与 Redis 缓存/Session/限流/短期状态等职责划分评审。
- 服务端权威模型设计：关键资产、奖励、经济、排行、共享状态和需要可信校验的结果由服务端权威判定。
- 同一基础框架兼容普通请求/响应型玩法与实时战斗型玩法，同时避免为了实时场景过度设计所有模块。
- Web / 微信小游戏 / 抖音小游戏的平台抽象与跨平台架构评审。
- API / 数据模型 / 存档兼容 / 第三方依赖评审。
- 性能、可靠性、安全性、可观测性和发布风险评估。
- 代码和架构 Review 标准制定与持续执行。
- 代码体积与复杂度治理：识别重复组件、公共方法、公共配置、重复协议定义和过大的业务模块，并推动 Client / Server Agent 重构优化。

- 部署与运行环境方案。
