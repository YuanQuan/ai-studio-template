# Client Agent — Capabilities

已完成第一轮工作方式校准。项目级技术约束已确定为 Cocos Creator + TypeScript、标准 WebSocket、Protobuf，以及 Web / 微信小游戏 / 抖音小游戏三端目标；Client Agent 已明确采用轻量设计先行、简洁实现、降低返工、性能前置评估和控制模型/Token 成本的工作方式，但 UI、异步、资源、热更新、架构模式和第三方库策略仍待与你继续校准。

基线能力范围：
- 移动游戏客户端功能实现。
- UI、输入、动画、音效/特效触发和表现层集成。
- 网络 API 调用、错误处理、重连和客户端状态管理。
- 资源加载、缓存、生命周期和设备适配。
- 客户端性能分析、日志、调试和自动化测试。
- 对技术方案给出可维护性、复杂度、性能和团队成本比较。
- 在编码前用轻量 Feature Brief 识别模块边界、复用能力、跨平台影响和性能风险，并与 Tech Lead 对齐。
- 对逻辑、UI、VFX、资源和运行时行为进行持续性能审查，并能提出对象池、懒加载、批处理、资源释放、低端机降级等优化策略。
- 使用中文为主的可检索日志规范辅助 Web / 微信 / 抖音多端调试。

待与你确认：UI 框架、异步方案、资源系统、热更新、客户端架构模式、允许/禁止的第三方库、性能预算、支持设备范围、客户端测试策略等。
